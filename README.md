# 批量二寸证件照生成器 v1.0

一个完全本地运行的免费批量证件照工具。适用于相机手持拍摄的竖版人物照片，自动识别人脸、尽量统一人物位置并输出二寸照片。

## 默认输出

- 二寸：35 × 49 mm
- 像素：413 × 579 px
- DPI：300
- JPEG：高质量
- 原文件名保留

> 35×49mm 是常见二寸规格。具体报名、考试、证件系统如另有尺寸要求，应以对方要求为准。

## 自动处理流程

1. 读取照片并根据 EXIF 自动转正。
2. 优先使用 OpenCV YuNet 检测最大人脸。
3. YuNet 可用时，根据双眼位置轻微纠正相机倾斜。
4. 将人脸水平居中，并统一人脸在最终画面中的大小和垂直位置。
5. 按 35:49 比例裁切。
6. 输出 413×579 JPEG 并写入 300 DPI。
7. 异常照片自动进入“人工复核”。
8. 生成 `处理报告.csv`。

## 异常照片

以下情况不会被强行裁切：

- 未检测到人脸
- 检测到多个明显人脸
- 人物距离相机太近，原图四周没有足够裁切空间
- 清晰度明显偏低（仍会输出成品，同时把原图复制到复核目录）

## 最简单使用方法（源码版）

Windows 10/11：

1. 安装 Python 3.11 或 3.12 64 位。
2. 安装时勾选 `Add Python to PATH`。
3. 解压本项目。
4. 双击 `run.bat`。
5. 第一次运行会安装依赖，并尝试下载 YuNet 模型。
6. 选择原始照片文件夹和输出目录，点击“开始批量处理”。

第一次安装需要联网。安装完依赖和模型以后可以断网使用。

## 打包成 Windows EXE

双击：

`build_exe.bat`

脚本会自动安装 PyInstaller 并打包。完成后在：

`dist\批量二寸证件照生成器\`

找到 EXE。

## YuNet 模型

程序会寻找：

`models\face_detection_yunet_2023mar.onnx`

可运行：

`python download_model.py`

自动从 OpenCV 官方 opencv_zoo 下载。

如果模型不存在，软件仍可启动，会使用 OpenCV 自带 Haar 人脸检测器。Haar 速度快但对侧脸、低光、角度变化的稳定性低于 YuNet，因此正式批量处理建议使用 YuNet。

## 两个构图参数

### 人脸高度占成片

默认 45%。

- 数字增大：脸更大、身体更少。
- 数字减小：脸更小、肩部/身体更多。

推荐先用 5–10 张照片试跑：`42%–48%`。

### 人脸中心垂直位置

默认 42%。

- 数字减小：人物整体更靠上。
- 数字增大：人物整体更靠下。

默认值适合常见胸像式证件照构图。

## 拍摄建议

为了让自动批处理稳定：

- 尽量正脸看镜头。
- 头顶、左右肩膀不要贴近照片边缘。
- 竖版拍摄。
- 背景尽量简单。
- 每张照片只有一位主要人物。
- 相机可以手持，但尽量不要倾斜超过约 10°。
- 曝光和对焦优先保证脸部清晰。

## 隐私

照片处理全部在电脑本地完成。本程序自身不会上传照片。

## v1.1 输出目录与人工复核

勾选“包含子文件夹”后，成品保留相对于原始照片目录的子目录结构，例如 A/一班/张三.png → 二寸成品/A/一班/张三.jpg。报告中的文件名也包含相对路径。

新增“开启人工复核”（默认开启）。开启时，需复核的原图放入 人工复核/原始相对路径，不再按原因分文件夹；原因记录在报告中。关闭时不创建或写入人工复核目录，无法处理的图片记为“跳过”，低清晰度图片仍输出并标记警告。之前已有的复核文件不会删除。

输出目录不能与原始照片目录相同；输出位于原始照片目录内部时，扫描会排除输出目录。


## v1.2 识别异常处理

新增“跳过识别异常照片”，默认勾选：未检测到人脸、检测到多人、构图空间不足或检测器报错时跳过成品输出。

取消勾选：上述照片按原图居中裁剪，保持比例后输出 413×579 像素、300 DPI JPEG；不再依赖人脸框构图，也不会把检测失败的照片强行当成成功识别。报告状态为“完成/警告”，说明中记录异常原因及直接输出方式。

人工复核开关独立生效：开启则复制异常原图到人工复核目录，关闭则不复制；两种输出方式都保留子目录结构。无法读取的损坏图片不能生成有效成品，仍跳过并记录原因。清晰度偏低仍按原来的规则输出并警告，不受此开关影响。
