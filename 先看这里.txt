批量二寸证件照生成器 v1.0

推荐使用顺序：

1. Windows 电脑安装 Python 3.11 或 3.12（64位），安装时勾选 Add Python to PATH。
2. 双击“一键运行.bat”。
3. 第一次运行会自动安装免费依赖，并尝试下载 OpenCV 官方 YuNet 人脸检测模型。
4. 软件打开后：
   - 选择“原始照片”文件夹
   - 选择“输出目录”
   - 默认参数先不用改
   - 点击“开始批量处理”
5. 输出目录会得到：
   - 二寸成品：413×579px / 300DPI JPG
   - 人工复核：无人脸、多人、构图空间不足、低清晰度等原图
   - 处理报告.csv

如果想以后电脑没有 Python 也能直接运行：
双击“一键打包EXE.bat”，打包完成后使用 dist 文件夹中的程序。

模型下载失败也不会导致软件打不开，会自动用 OpenCV Haar 备用检测器；但正式大批量建议使用 YuNet。

详细说明请看 README.md。
